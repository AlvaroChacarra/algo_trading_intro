# Introducción al Algo Trading con Python — ICAI 2026

Construimos un sistema de trading y backtesting, pieza a pieza.

1. [Ver las presentaciones](https://alvarochacarra.github.io/algo_trading_intro/): abre la web y pulsa **Presentación**. En local, doble clic en `index.html`; sin servidor.
2. [Preparar Python y Jupyter](GUIA_LOCAL.md): una sola instalación dentro del repositorio.
3. En L1–L3, resuelve el **principal y los auxiliares en notebooks**. Después puedes ejecutar el mismo principal como `.py`.

```bash
git clone https://github.com/AlvaroChacarra/algo_trading_intro.git
cd algo_trading_intro
```

Guarda tus respuestas junto a las plantillas como `mi_principal.ipynb`, `mi_auxiliar.ipynb` y `mi_main.py`. Recibe nuevas clases con `git pull --ff-only`; no necesitas hacer push.

El notebook sirve para investigar y explicar; los `.py`, para ejecutar programas completos y crear funciones reutilizables. En L4–L14 continuamos el proyecto acumulativo descrito en [su guía](GUIA_PROYECTO.md).

Sesión estándar: unos 50 minutos —10 de test, 20 de presentación, 20 de práctica—. Evaluación: asistencia 10%, participación 20%, continua 40%, final 30%. En sesiones consecutivas, el test se difiere hasta haber tenido tiempo de estudio.

Datos sintéticos y experimentos docentes. El backtest de snapshots y el simulador de market making son entornos distintos. La autoría y evaluación oficial viven en el source privado; este material se publica según el calendario del curso.
