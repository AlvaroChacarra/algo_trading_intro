# Guion — Clase 1: Python I — El modelo de datos

**Idea central:** Un algoritmo es siempre lo mismo: dato <span class='dot'>→</span> cálculo <span class='dot'>→</span> decisión.

Presentación de 3 bloques (~5-7 min cada uno) + hero + cierre.


## Bloque 1: Tu código es texto que un programa ejecuta

- **Qué decir:** Un archivo .py no es magia: es texto. Python lo lee de arriba abajo y produce un resultado. Si algo falla, el error te dice exactamente dónde mirar — es información, no un castigo.
- **Acción en pantalla:** mostrar el snippet del bloque 1 y ejecutarlo en el notebook.

## Bloque 2: Datos con nombre: variables, listas y diccionarios

- **Qué decir:** Una variable guarda un valor. Una lista agrupa varios. Un diccionario agrupa piezas con significado — justo lo que es una orden: side, price, size.
- **Acción en pantalla:** mostrar el snippet del bloque 2 y ejecutarlo en el notebook.

## Bloque 3: Del dato a la decisión: for e if

- **Qué decir:** Un for repite trabajo sobre muchos datos; un if convierte una observación en una decisión. Con esas dos piezas ya puedes recorrer un libro de órdenes y reaccionar.
- **Acción en pantalla:** mostrar el snippet del bloque 3 y ejecutarlo en el notebook.
