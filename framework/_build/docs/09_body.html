§2 · Construcción acumulativa de la API

step, timestamp, submit y reset dejan de ser magia

La clase completa permanece a la izquierda. A la derecha sigues la línea que cambia el estado o delega trabajo.

núcleo presencial

0/6step: avanzar el cursor

_i parte en −1. Incrementarlo antes de leer hace que el primer step() apunte al índice 0.

núcleo presencial

1/6step: reconstruir el estado

La fila actual sigue siendo un dict. OrderBook.from_snapshot, construido en L7, lo convierte en el book actual.

núcleo presencial

2/6step: definir el final

Si el cursor sale de la secuencia, book=None y return None. Si no, devuelve el nuevo book. Ya puedes leer step() entero.

3/6¿De dónde sale timestamp?

Es una property derivada de la fila señalada por _i. No es estado duplicado: consulta el snapshot actual.

núcleo presencial

4/6submit: fallar pronto y delegar

Sin book, RuntimeError. Con book, Market pasa orden, book y timestamp al engine de L8 y devuelve sus fills.

núcleo presencial

5/6Market HAS-A MatchingEngine

Market coordina; MatchingEngine cruza; OrderBook guarda estado. No existe una relación “Market es un engine”.

consolidación requerida

6/6reset: volver al origen

Solo restaura _i=-1 y book=None. Los snapshots y el engine siguen existiendo.

class Market:    def __init__(self, symbol, snapshots, depth=10):        self.symbol = symbol        self._snapshots = snapshots        self._depth = depth        self._engine = MatchingEngine()        self._i = -1        self.book = None    @property    def timestamp(self):        if 0 <= self._i < len(self._snapshots):            row = self._snapshots[self._i]            return int(row.get("timestamp", self._i))        return None    def step(self):        self._i += 1        if self._i >= len(self._snapshots):            self.book = None            return None        self.book = OrderBook.from_snapshot(            self.symbol, self._snapshots[self._i], self._depth)        return self.book    def submit(self, order):        if self.book is None:            raise RuntimeError("llama a step() primero")        return self._engine.process(            order, self.book, self.timestamp)    def reset(self):        self._i = -1        self.book = None
