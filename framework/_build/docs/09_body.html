§2 · Construye la API

step, submit y reset dejan de ser magia

0/5step: avanzar

self._i += 1. El cursor cambia antes de leer la fila.

1/5step: reconstruir

La factory de L7 convierte el snapshot actual en OrderBook.

2/5step: agotamiento

Sin más filas: book=None y return None. Esa será la salida del while.

3/5submit: guard + delegación

Sin book, RuntimeError. Con book, Market llama al engine de L8 y devuelve sus fills.

4/5Market no hace matching

Contiene un MatchingEngine. Delegar preserva una sola implementación del algoritmo.
