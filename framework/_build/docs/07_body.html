§1 · De fila a objeto

Una transformación, siete decisiones

El panel izquierdo conserva el código que ya has construido. El derecho enseña un único cambio de estado.

núcleo presencial

0/6La fila externa

El feed trae nombres y números. Todavía no hay objetos que protejan qué valores deben viajar juntos.

núcleo presencial

1/6¿Por qué nace Level?

price sin size no describe un nivel. La dataclass crea dos atributos y genera el constructor por nosotros.

Order ≠ Level: una orden es intención individual; un nivel es liquidez agregada a un precio.

núcleo presencial

2/6Separar los dos lados

Cada Level válido entra en bids o asks. Un tamaño no positivo no representa liquidez disponible.

núcleo presencial

3/6Imponer la invariante

Bids: mayor precio primero. Asks: menor precio primero. Ordenar en __init__ garantiza que el índice 0 siempre sea el mejor nivel.

consolidación requerida

4/6La necesidad antes de la sintaxis

Si ya tienes listas, usas el constructor normal. Si tienes una fila externa, necesitas una entrada alternativa que primero la transforme.

consolidación requerida

5/6Ahora sí: la factory

@classmethod recibe la clase como cls. Tras fabricar los niveles, cls(symbol, bids, asks) llama al constructor normal.

consolidación requerida

6/6El contrato resultante

Desde aquí nadie conoce columnas del CSV: todo el sistema consulta métodos y propiedades de OrderBook.

@dataclassclass Level:    price: float    size: floatclass OrderBook:    def __init__(self, symbol, bids, asks):        self.symbol = symbol        self.bids = sorted(bids, key=lambda lv: -lv.price)        self.asks = sorted(asks, key=lambda lv: lv.price)    @classmethod    def from_snapshot(cls, symbol, row, depth=10):        bids, asks = [], []        for i in range(1, depth + 1):            bp, bs = row.get(f"bid_price_{i}"), row.get(f"bid_size_{i}")            ap, az = row.get(f"ask_price_{i}"), row.get(f"ask_size_{i}")            if bp is not None and bs is not None and float(bs) > 0:                bids.append(Level(float(bp), float(bs)))            if ap is not None and az is not None and float(az) > 0:                asks.append(Level(float(ap), float(az)))        return cls(symbol, bids, asks)    @property    def best_bid(self):        return self.bids[0].price if self.bids else None    @property    def best_ask(self):        return self.asks[0].price if self.asks else None    def depth(self, side, levels=10):        book_side = self.bids if side is Side.BUY else self.asks        return sum(lv.size for lv in book_side[:levels])    def imbalance(self, levels=1):        bid_vol = self.depth(Side.BUY, levels)        ask_vol = self.depth(Side.SELL, levels)        total = bid_vol + ask_vol        return None if total == 0 else (bid_vol - ask_vol) / total    @property    def microprice(self):        if not self.bids or not self.asks: return None        bid_size, ask_size = self.bids[0].size, self.asks[0].size        return (self.best_bid * ask_size + self.best_ask * bid_size) \               / (bid_size + ask_size)

§4 · Fija el mecanismo
5 preguntas

  
¿Qué representa Level(price, size)?
Order modela intención; Level modela estado agregado del libro.

  
¿Por qué ordenar en __init__?
El constructor impone la invariante.

  
cls(...) dentro de @classmethod significa…
La factory transforma la entrada y termina llamando al constructor normal.

  
¿Cómo debe implementarse imbalance?
Una sola definición de profundidad.

  
¿Dónde debe conocer el sistema nombres como bid_price_1?
La transformación externa se encapsula en la frontera.
