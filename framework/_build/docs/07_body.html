§1 · De fila a objeto

Una transformación, cinco decisiones

Avanza por la traza. Cada parada muestra una línea activa y un único cambio de estado.

0/5La fila externa

El feed trae nombres de columna y números. Todavía no hay objetos ni invariantes.

1/5Dos números → un Level

Level(price, size) agrupa estado que siempre viaja junto.

2/5Separar responsabilidades

Cada Level entra en bids o asks. Tamaños no positivos se descartan.

3/5Ordenar una sola vez

Bids: mayor precio primero. Asks: menor precio primero. Así, el mejor nivel siempre ocupa índice 0.

4/5La factory

cls(...) fabrica el mismo tipo desde otra representación. El CSV queda encapsulado.

5/5El contrato resultante

Desde aquí nadie pregunta por columnas: consulta best_bid, depth, imbalance o microprice.
