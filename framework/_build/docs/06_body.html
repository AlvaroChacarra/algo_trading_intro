Una familia de estrategias

Este curso acaba contigo escribiendo tu propia estrategia y enchufándola a un motor. Ese enchufe se fabrica hoy. El problema: vas a escribir muchas estrategias… y todas comparten esqueleto.

el pecado de siempre, ahora con clasespython
class MomentumStrategy:    def __init__(self, name): self.name = name   # igual…    def decide(self, book): return 'buy'class MeanRevStrategy:    def __init__(self, name): self.name = name   # …que aquí    def decide(self, book): return 'sell'
El reto de hoy

Solo cambia la decisión; el esqueleto se repite. Copiarlo N veces es el mismo pecado de L2 — y ya sabes cómo huele.

Hoy aprendes las tres piezas que lo curan: herencia (una base con el esqueleto), polimorfismo (una llamada, muchas respuestas) y la ABC (el contrato que impide subclases a medio hacer). Es la semilla del framework de estrategias de L10.

~40 min lectura + práctica 7 secciones 2 simuladores lo cian se toca
§1 · La idea central

El árbol genealógico

Sigue bajando: el panel planta la clase base y hace crecer la familia hasta el momento estrella — el bucle que las trata a todas por igual.

0/5Dos clases gemelas

Mira el panel: el __init__ es idéntico, la estructura es idéntica. Con 10 estrategias tendrás 10 copias — y el día que el esqueleto cambie, 10 sitios que tocar.

1/5La base: Strategy

El esqueleto se escribe una vez, en una clase madre: el __init__ común y un decide(book) por defecto (el más prudente: 'hold').

2/5Heredar: todo gratis

class Momentum(Strategy) — ese paréntesis es la herencia. La hija nace con todo lo de la madre: su __init__, su decide, sus futuros métodos.

Una subclase vacía ya funciona. Aburrida, pero funciona.

3/5Override: cambia solo lo tuyo

La hija redefine decide() y su versión gana. El resto sigue heredado. Este es el reparto perfecto: el esqueleto en un sitio, la personalidad en cada hija.

4/5El momento estrella: polimorfismo

Un bucle recorre una lista de estrategias distintas y a todas les dice lo mismo: s.decide(book). Cada una responde a su manera.

El bucle no sabe ni le importa qué clase es cada una. Ese desacople es lo que hará enchufable el motor.

5/5El contrato: ABC

¿Y si alguien escribe una estrategia sin decide()? Con una clase base normal, el error explota tarde, en mitad del backtest. Con @abstractmethod, Python ni siquiera deja crear el objeto incompleto. El error se adelanta al mejor momento posible: ya.

from abc import ABC, abstractmethod

class Strategy(ABC):
    @abstractmethod
    def decide(self, book): ...

class Incompleta(Strategy):
    pass   # sin decide()

super() en una frase
    "Madre, haz tu parte." La hija no copia el __init__ de la base — lo
    invoca y luego añade lo suyo. Si mañana la base guarda algo más, todas
    las hijas lo heredan sin tocarlas.
