§2 · Construye

La fábrica y el libro

Tres funciones cortas y el libro ya vive. Fíjate en el patrón: cada función hace una cosa y tiene un nombre que no necesita comentario.

def make_order(symbol, side, price, size):    return {'symbol': symbol, 'side': side, 'price': price, 'size': size}def add_order(book, order):    book.append(order)    return bookbook = []book = add_order(book, make_order('BTCUSDT', 'buy', 99950, 0.5))print(book)
>>> [{'symbol': 'BTCUSDT', 'side': 'buy', 'price': 99950, 'size': 0.5}]

¿Y cancelar? La forma más limpia es construir un libro nuevo sin la orden condenada — una comprensión de lista:

order_book.py (sigue)python
def cancel_order(book, order_id):    return [o for o in book if o.get('id') != order_id]
Lee la comprensión en voz alta "Una lista con cada orden o del book… si su id no es el condenado." No borra dentro de la lista vieja: devuelve una nueva. Es la primera vez que ves esta sintaxis — en el gimnasio la entrenas.

§4 · Construye

Leer el libro: métricas y señal

Las funciones de lectura no tocan el libro — lo resumen. Componlas y tienes el cuadro de mandos de L1, ahora para N activos sin duplicar nada.

order_book.py (lectura)python
def best_bid(book):    return max(o['price'] for o in book if o['side'] == 'buy')def imbalance(book):    buy_size  = sum(o['size'] for o in book if o['side'] == 'buy')    sell_size = sum(o['size'] for o in book if o['side'] == 'sell')    return buy_size / (buy_size + sell_size)
Predice antes de ejecutar

El libro tiene tres órdenes: buy 0.3, buy 0.3 y sell 0.2. ¿Qué devuelve imbalance(book)?

>>> 0.75 # 0.6 de compra / 0.8 total — presión compradora
Honestidad Este imbalance suma todo el libro. Los profesionales suelen mirar solo los primeros niveles (los precios cerca del mid pesan más). Lo refinaremos cuando leamos el libro real en la clase 7.
§5 · Fija lo de hoy

5 preguntas

¿Qué devuelve make_order('BTCUSDT', 'buy', 99950, 0.5)?
Es una fábrica: recibe los campos y return el dict ya montado, siempre con las mismas claves.
book.append(order) — ¿qué le pasa a book?
append muta la lista original. Compáralo con la comprensión de cancel_order, que construye una nueva.
La comprensión [o for o in book if o.get('id') != order_id]…
Filtra construyendo una lista nueva. El book viejo queda intacto — por eso la función hace return.
imbalance(book) devuelve 0.75. ¿Qué está diciendo el libro?
imbalance = tamaño comprador / tamaño total. 0.75 = presión compradora clara; 0.5 sería equilibrio.
Las 7 funciones de hoy comparten algo sospechoso. ¿Qué?
Un dato y el equipo de funciones que lo manosean, viajando siempre juntos… eso tiene nombre: objeto. Llega en la clase 4.
