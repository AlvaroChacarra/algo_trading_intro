Bloque 3 — Cuando confiar, cuando verificar

El semaforo de confianza

No todo el codigo de una IA merece el mismo nivel de revision. Aprende a calibrar tu confianza segun lo que pides.

Verde — Confiar
Boilerplate, formateo, funciones puras simples. Facil de verificar con los ojos.
Amarillo — Revisar
Logica de negocio, calculos financieros, estado mutable. Requiere tests o ejecucion manual.
Rojo — No confiar
Seguridad, autenticacion, datos sensibles, operaciones irreversibles. Siempre verificar a fondo.
