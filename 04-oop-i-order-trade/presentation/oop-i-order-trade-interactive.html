OOP I — Order y Trade

Convertir el dict de orden en una clase Order con métodos, y modelar el resultado de un cruce con Fill. Primer módulo de verdad del paquete exchange.

Hoy construyes: clases Order y Fill (exchange/orders.py, trades.py)
Bloque 1

De dict a clase

Una clase es una plantilla. `__init__` guarda los datos (lo que antes eran claves del dict) como atributos. Crear un objeto es rellenar la plantilla.

class Order:
    def __init__(self, symbol, side, price, size):
        self.symbol = symbol
        self.side = side
        self.price = price
        self.size = size
Bloque 2

Métodos: el dato sabe operar consigo mismo

Antes tenías compute_notional(order). Ahora la orden lo sabe hacer sola: order.notional(). El comportamiento vive junto al dato.

    def notional(self):
        return self.price * self.size
Bloque 3

Fill: el resultado de un cruce

Cuando una orden se ejecuta, genera un Fill. Su cash_flow es negativo si compras (sale caja) y positivo si vendes.

    def cash_flow(self):
        sign = -1 if self.side=='buy' else 1
        return sign * self.price * self.size
Cierre

Un objeto empaqueta datos y comportamiento: la orden ya sabe calcular su nocional.
